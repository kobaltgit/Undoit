# Политика безопасности (Security Policy)

## Поддерживаемые версии

Исправления безопасности и обновления выпускаются для актуальной мажорной версии **Undoit v2.x**.

| Версия | Статус поддержки |
| :--- | :--- |
| **2.x.x (Rust / Tauri)** | :white_check_mark: Активно поддерживается |
| 1.x.x (Python / Qt) | :x: Устарела (ветка `v1-python`) |

---

## Сообщение об уязвимости

Мы серьезно относимся к безопасности пользователей и сохранности их локальных данных. Если вы обнаружили потенциальную уязвимость:

1. **Не создавайте публичный Issue** на GitHub с описанием уязвимости.
2. Воспользуйтесь функцией приватного отчета на GitHub:
   - Перейдите во вкладку [Security](../../security).
   - Нажмите **Report a vulnerability** («Сообщить об уязвимости»).
3. Опишите:
   - Тип уязвимости и потенциальные риски.
   - Подробные шаги для воспроизведения (PoC / сценарий).
   - Версию Undoit и ОС (Windows 10/11).

Мы изучим отчет, выпустим закрытый патч и публично укажем вашу благодарность в примечаниях к релизу (если вы не против).
