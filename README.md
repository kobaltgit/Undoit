## 💡 О проекте

**Undoit** — это легковесная локальная утилита непрерывного сохранения версий (Time Machine) для Windows. При каждом изменении файла в отслеживаемых папках Undoit автоматически создает моментальный снимок, позволяя в любой момент вернуться к любому состоянию, изучить изменения или восстановить случайно перезаписанный документ.

Версия **v2.0** полностью переписана на **Rust** и **Svelte 5** с использованием движка **Tauri v2**, потребляет **меньше 25 МБ оперативной памяти** и работает в разы быстрее предыдущей версии на Python.

> 📦 *Архивная версия v1.0 на Python сохранена в ветке [`v1-python`](https://github.com/kobaltgit/Undoit/tree/v1-python).*

## ✨ Ключевые возможности

### 🚀 Высокая производительность и компактность
* **Ядро на Rust:** Моментальная реакция на события файловой системы с дебаунсингом и обработкой блокировок Windows (Sharing Violation).
* **Сжатие Zstandard (zstd):** Экономия дискового пространства до 70–80% по сравнению с несжатыми файлами.
* **BLAKE3 CAS Хранилище:** Контентно-адресуемая дедупликация данных — если файл пересохранили без изменений, дубликат не создается.
* **Легковесность:** Приложение занимает всего ~15 МБ на диске и использует минимум ресурсов процессора.

### 🖼️ Визуальное сравнение (Visual Diff)
* **Изображения (PNG, JPG, SVG, WebP, GIF, BMP, TIFF, AVIF, ICO):**
  - Интерактивная **шторка-слайдер («До / После»)** с фиксацией пресетов (0%, 25%, 50%, 75%, 100%).
  - Режим **Side-by-side** (сравнение версий рядом).
  - Плавное масштабирование **Zoom** от 25% до 300%.
* **PDF документы (`.pdf`):**
  - Визуальный рендеринг страниц в высоком качестве через `pdf.js`.
  - Постраничная навигация (`◀ Стр. 1 из N ▶`) со сравнением любой страницы.
* **Adobe Illustrator (`.ai`):**
  - Отрисовка векторных макетов через встроенный PDF-поток или XMP-растровое превью.

### 📝 Умный текстовый Diff
* **Документы Microsoft Word (`.docx`):**
  - Автоматическое извлечение текста абзацев прямо из архива в памяти.
  - Полноценный построчный зелёно-красный Diff изменений текста договора, статьи или ТЗ.
* **Исходный код и текстовые файлы (`.txt`, `.json`, `.md`, `.rs`, `.py`, `.ts`, `.html` и др.):**
  - Детальный diff с номерами строк и подсветкой добавленных и удаленных фрагментов.

### 👁️ «Открыть в приложении»
* В один клик открывайте любой исторический снимок макета или документа в ассоциированной системной программе (Microsoft Word, Adobe Illustrator, Acrobat Reader, Photoshop и т.д.) во временном защищенном файле без риска испортить текущий рабочий проект.

### 🪟 Глубокая интеграция с Windows
* **Контекстное меню Проводника:** Пункт *«История версий Undoit»* для любых файлов, папок и фона папок.
* **Single Instance IPC:** Открытие файла через контекстное меню мгновенно фокусирует существующее окно программы (через Named Mutex и Named Pipe).
* **Интеллектуальный трей:** Векторная иконка-щит динамически меняет цвет и отображает круговую диаграмму заполненности диска. Контекстное меню трея позволяет ставить мониторинг на паузу, запускать очистку и открывать настройки.
* **Автозапуск с Windows:** Опция сворачивания в трей при старте системы.

### 🔒 100% Конфиденциальность
* Все данные, снимки и база метаданных SQLite хранятся **исключительно на вашем компьютере** в папке `%APPDATA%\Undoit\`. Никаких облачных серверов, телеметрии и учетных записей.

## 📊 Сравнение версий

| Характеристика | Undoit v1 (Legacy) | Undoit v2 (Current) |
| :--- | :--- | :--- |
| **Стек технологий** | Python + PyQt5 | **Rust + Tauri v2 + Svelte 5** |
| **Потребление ОЗУ** | ~140–180 МБ | **~20–25 МБ** |
| **Размер программы** | ~70–90 МБ (PyInstaller) | **~15 МБ (Единый бинарник .exe)** |
| **Алгоритм сжатия** | Без сжатия / zip | **Zstandard (zstd) + BLAKE3 CAS** |
| **Визуальный diff** | Базовый просмотр картинок | **Интерактивная шторка, Zoom, PDF, AI** |
| **Поддержка Word DOCX** | Бинарный файл без diff | **Построчный текстовый diff абзацев** |
| **Windows Shell** | Частичная интеграция | **Контекстное меню + Named Pipe IPC** |

## 📦 Установка и запуск

### Готовые сборки (Windows x64)

Скачайте релиз со страницы [Releases](../../releases):
1. **Портабельная версия (`Undoit.exe`):**  
   Не требует установки. Просто запустите файл в любой папке.
2. **Инсталлятор (`Undoit-setup.exe` или `.msi`):**  
   Классический установщик Windows с ярлыками и интеграцией в систему.

## 🛠️ Сборка из исходников

### Требования
* [Node.js](https://nodejs.org/) (v18 или новее)
* [Rust toolchain](https://rustup.rs/) (актуальная стабильная версия)
* Visual Studio C++ Build Tools (компоненты C++ для сборки под Windows)

### Инструкция

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/kobaltgit/Undoit.git
   cd Undoit
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите в режиме разработки:
   ```bash
   npm run tauri dev
   ```

4. Соберите релизный бинарник и инсталлятор:
   ```bash
   npm run tauri build
   ```
   Готовые файлы появятся в `src-tauri/target/release/`.
